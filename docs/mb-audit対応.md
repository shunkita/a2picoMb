# a2picoMb mb-audit 対応および 6522 VIA / AY-3-8913 実装改善まとめ

## 1. 概要と開発方針

本ドキュメントは、Mockingboard エミュレータ（a2picoMb）において mb-audit テストスイートへの適合性向上、および実機互換性の是正を行った実装項目を整理したものである。

### 基本方針

- **機能不全・論理バグの完全是正**: 未実装レジスタ、スロットマッピング、タイマー基本動作、AY リードバックなど、実機仕様と異なる論理欠陥はすべて修正し維持する。
- **微小タイミング問題の棚上げ**: Apple II バスサイクル境界（Phi0 クロック、ナノ秒単位の過渡電圧やオープンバス浮遊値）に依存する極限のタイミング問題は、Core 1 の 200MHz ポーリングおよび既存の音声合成パイプラインの安定性を最優先とし、現状の処理構造で無理な深追いは行わず一旦棚上げとする。
- **音声出力の非デグレード維持**: Skyfox 等の実機ゲームにおける音声再生が正常に機能している状態を絶対防衛ラインとする。

---

## 2. 実装・修正項目の詳細一覧

### ① 6522 VIA コア・レジスタ実装の是正（グループ A: 仕様是正）

1. **スロットアドレス空間のフルミラーリング ($Cn00〜$CnFF)**
   - main では $Cn00-$Cn0F（VIA 0）および $Cn80-$Cn8F（VIA 1）以外の領域がオープンバスとなっていた。
   - アドレスオフセットの Bit 7（`offset & 0x80`）による直接ルーティングを導入し、16 バイト周期での完全ミラーリングを確立。カード自動検出が正常化。
2. **シフトレジスタ（SR: $0A）の挙動実装**
   - REG_SR の Read / Write および IFR bit 2（SR 割り込みフラグ）の連動を実装。未定義値返却を排除。
3. **IER（$0E）/ IFR（$0D）の仕様準拠（リードバック整合性）**
   - IER 読み出し時に Bit 7 を常に 1（`via->ier | 0x80`）として返却するハードウェア仕様へ準拠。
   - IFR 読み出し時に `(IFR & IER) != 0` の場合のみ Bit 7（IRQ フラグ）を立てる論理合成を適用。
   - タイマーやポートアクセスに伴う IFR 各ビットのクリア動作を適正化。
4. **ポート A / ポート B のリードバックおよびプルアップ**
   - ORA / ORB / DDRA / DDRB に対する書き込み値のリードバック、およびオープンピン時のプルアップ挙動（0xFF）を整理。

### ② AY-3-8913（PSG 音源）制御系の実装（グループ A: 仕様是正）

5. **AY レジスタの Readback（Control = 5）実装**
   - main では欠落していた「AY レジスタ読み出し」に対応。
   - `ay_regs[2][16]` シャドウバッファおよび各レジスタ固有のビット有効マスク（`ay_reg_mask[16]`）を新設し、Control = 5（READ）時に `target_via->in_a` へ値を供給。
6. **AY バス制御ステート（Control = 4: INACTIVE, Control = 0: RESET）の実装**
   - INACTIVE（$04）および RESET（$00）時に `in_a = 0xFF`（バス浮遊復帰）を保証。
   - RESET 時にシャドウレジスタ全ゼロクリアとオーディオキューへのリセット通知を実行。

### ③ タイマー・割り込み機構の是正（グループ A: 仕様是正）

7. **Timer 2 の常時自走（Free-running）化**
   - main の「減算を停止させる」処理を撤廃し、アセンブラループ（`subs cnt, cnt, #1`）により常時自走減算を継続。差分時間計測による Mockingboard 検出ルーチンをパス可能に改善。
8. **Timer 2 のワンショット割り込み制御（t2_armed）**
   - T2CH 書き込みで `t2_armed = 1`（アーム）、初回のアンダーフローでのみ IFR bit 5 をセットして `t2_armed = 0`（ディスアーム）となる一回限り割り込みを適正化。
9. **Timer 1 のアンダーフロー時リロード**
   - アンダーフロー発生時にラッチ値（`t1_latch`）からカウンタへ再ロードする処理を確立。

### ④ 局所タイミング補正（グループ B: 局所調整・棚上げ対象）

10. **Timer 1 / Timer 2 初動 1 サイクル遅延補正（方法 A）**
    - REG_T1CH / REG_T2CH 書き込み時に初期値へ +1 を加算。書き込み直後の 1 クロック減算保留を模倣し、15 サイクル後リードで N - 14（Expected: $F1）を返す挙動を確立（Test 11:03/04 をクリア）。
11. **REG_T1CH アンダーフロー過渡値補正**
    - カウンタが 0 から -1（0xFFFF）に落ちた瞬間の一時的過渡状態において、WaitT1Underflow ポーリングループの誤脱出を防ぐためラッチ上位バイトを返却する安全処理。

### ⑤ ハードウェア・バス防衛（グループ A: 仕様是正）

12. **構造体オフセットおよびサイズのコンパイル時強制静的検証**
    - `_Static_assert` により、C 構造体の配置とアセンブラハードコードオフセット（#14, #17, #20, #23, sizeof==24）の完全一致を保証。構造体改変によるメモリ破壊を永続防止。

## 4. 残存課題と今後の展望

- **Test 11:0A:02（REG_T1CL アンダーフロー直後リード）**:  
  アンダーフロー発生時の `update_irq()` 等の処理負荷により、6502 の Phi0 立ち下がりサンプリングに対してバスデータ供給がわずかに遅延し、オープンバス浮遊値（直前の命令コード $A0）が読まれる事象。
- **Test 60:01:00（DDRB データバス全走査）**:  
  高速連続アクセス中におけるリードサイクル Fast Path のセットアップマージン。

上記課題は、タイマーやレジスタの論理的欠陥ではなく、Core 1 の 200MHz 処理タイミングと Apple II バス同期の境界マージンに起因する。実機ソフトウェア（Skyfox 等）の音声合成・タクト割り込み動作には一切支障がないため、現行の処理構造の安定性を優先し、本段階ではこれ以上の追求を行わず保留とする。
