# Language Rules (Strict English-Only in Codebase)

## 1. User Interaction
- Always converse with the user in **Japanese** (全て日本語で応答すること).

## 2. Codebase Implementation (STRICT REQUIREMENT)
- **ALL code comments, docstrings, variable/function names, commit messages, and in-code strings MUST be in ENGLISH.**
- **Japanese characters (漢字、ひらがな、カタカナ) in source code files are STRICTLY PROHIBITED.**
- When implementing features or copying logic from instructions/pseudocode containing Japanese comments, **ALWAYS translate them into professional, concise English**. Never paste Japanese comments into code.
